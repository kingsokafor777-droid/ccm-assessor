# Security policy

## Scope

ccm-assessor handles assessment metadata and content-addressed evidence references. It is not a credential store, evidence-payload store, cloud collector, or production control plane.

## Reporting

Report vulnerabilities privately through GitHub Security Advisories. Do not include real tenant identifiers, raw evidence, tokens, secrets, or connection strings in issues, logs, fixtures, or pull requests.

## Operational responsibilities

Deployers own authentication, authorization, tenant isolation, evidence-storage encryption, retention execution, baseline authorization, and framework mapping governance. A deterministic assessment manifest is not an audit or certification artifact by itself.
